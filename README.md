# SafetYSec

SafetYSec is an **Android mobile application** designed to improve user safety through **activity monitoring**, **fall detection**, and an **alert system**.  
The project is developed in **Kotlin**, using **Jetpack Compose** for UI and **Firebase** as the backend.

## ✨ Features

- 🔐 **User Authentication**
  - User registration and login
  - Password reset
  - User role management (e.g. monitored user / caregiver)

- 📡 **User Monitoring**
  - Collecting data from device sensors
  - Real-time event analysis
  - Configurable monitoring rules

- 🚨 **Fall Detection**
  - Detection of sudden movements and impacts
  - Automatic alert triggering
  - Emergency notifications

- 🔔 **Notification System**
  - Alerts sent to assigned caregivers
  - Real-time updates using Firebase

- 📱 **Modern UI**
  - Built with Jetpack Compose
  - Clean and responsive interface

## 🛠️ Technologies Used

- **Kotlin**
- **Android SDK**
- **Jetpack Compose**
- **Firebase Authentication**
- **Firebase Realtime Database / Firestore**
- **MVVM architecture**
